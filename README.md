# GoPhish Awareness Lab (Ubuntu 24.04)

This repository documents a controlled **security awareness simulation lab** deployed using GoPhish on Ubuntu 24.04.

The purpose of this project is to demonstrate how phishing-awareness training infrastructure can be deployed safely for **educational and defensive security training environments**.

---

# Project Goals

This lab demonstrates:

- awareness campaign infrastructure setup
- secure Ubuntu 24.04 deployment
- Gmail SMTP sending profile configuration (App Password authentication)
- awareness training email template creation
- landing page awareness workflow
- campaign metric analysis

---

# Lab Environment

| Component | Version |
|----------|---------|
| OS | Ubuntu 24.04 |
| Awareness Engine | GoPhish |
| SMTP | Gmail SMTP |
| Authentication | Google App Password |
| Reverse Proxy | Optional NGINX |
