# Lab Architecture

The awareness lab consists of four main components:

User → Email Template → GoPhish Server → Training Landing Page

---

# Components

Ubuntu 24.04 Server

Hosts GoPhish application.

GoPhish Platform

Provides:

campaign manager  
template editor  
landing page hosting  
tracking metrics  

SMTP Provider

Gmail SMTP used for awareness email delivery.

Training Landing Page

Displays awareness confirmation message after interaction.
