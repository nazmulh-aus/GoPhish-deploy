# Project Overview

Security awareness simulations help organisations measure how users respond to suspicious email scenarios.

This lab demonstrates how to deploy a safe phishing-awareness training platform using GoPhish.

---

# Training Objectives

The lab environment supports:

- suspicious email recognition training
- link validation awareness
- urgency detection awareness
- reporting workflow improvement

---

# Awareness-First Design

This lab prioritises:

education  
transparency  
training effectiveness  
safe simulation practices
